Sales Dashboard

Built a complete Power BI dashboard from a ~3,000-row dataset that did not even have a sales column to begin with.

Power BIPower QueryData ModelingDAXStar Schema
🔴 Live interactive report — try the real filters yourself

The challenge

This dataset was a different kind of challenge: around 3,000 rows brought into Power Query, with a very large number of missing values throughout — and no explicit sales column at all. The raw data only had unit price and quantity sold per order.

The approach

1. Understand the raw data

I first explored the data to understand the business behind it and identify what could be derived reliably from the available fields.

2. Construct the core metric

I built a proper Sales column by multiplying unit price by quantity.

3. Clean and model

After cleaning the missing values, I split the data into dimension and fact tables using a Star Schema approach, loaded the model into Power BI, and wrote DAX measures on top of it.

4. Build the dashboard

The dashboard includes KPI cards for sales, orders, and customers, a monthly sales trend, a top-customers ranking, a product-line breakdown, a deal-size donut chart, a territory comparison, and a country map.

Result

A full sales dashboard built from data where the core metric — sales — did not exist yet and had to be constructed first. It pushed me to think about the data model, not just the visuals, before building anything.

What this project demonstrates

  • Deriving a business metric from raw fields
  • Power Query cleaning and preparation
  • Fact/dimension modeling in Power BI
  • DAX measure design
  • Dashboard storytelling across KPIs, trends, rankings, categories, territories, and geography
